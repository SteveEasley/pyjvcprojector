# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Commands

Tooling is managed with uv. Dev tool versions in `pyproject.toml` and `.pre-commit-config.yaml` are pinned to match Home Assistant's.

**Setup:**
```bash
uv sync
uv run prek install   # optional: run the hooks on every commit
```

**Lint, format & type-check (all prek hooks: ruff, codespell, zizmor, yamllint, mypy, pylint):**
```bash
uv run prek run --all-files
```

**Run all tests:**
```bash
uv run pytest
```

**Run on another Python version (3.11 is the minimum supported):**
```bash
uv run --python 3.11 pytest
```

**Run a single test:**
```bash
uv run pytest tests/test_projector.py::test_name
uv run pytest -k "pattern"
```

**Regenerate the command imports after adding a command:**
```bash
uv run python tools/update_imports.py
```

**Build:**
```bash
uv build
```

## Architecture

pyjvcprojector is an async Python client for controlling JVC projectors over the JVC network protocol (TCP).

### Layered design (bottom to top)

1. **`connection.py`**: Transport layer. A thin wrapper over an asyncio stream with per-read timeouts.

2. **`device.py`**: Protocol layer. `Device` performs the PJ_OK/PJREQ/PJACK handshake (with optional password auth), frames operation and reference commands, and validates acks. Sends are serialized and throttled, a connection is opened per burst of commands and closed `KEEPALIVE_TTL` after the last one, and any error other than `JvcProjectorCommandError` drops the connection immediately.

3. **`command/`**: Command definitions.
   - `base.py` defines `Command` (subclasses self-register by name and code), the `Parameter` types that convert between human-readable and native values, and `Spec`/`Model`, which map projector models to protocol specifications. Unknown models fall back to `LIMP_MODE`.
   - `command.py` declares `SPECIFICATIONS` and every command class. A command's `parameter` may be a single `Parameter` or a dict keyed by spec (or tuple of specs) for model-specific values.
   - `__init__.py` re-exports every command; its import list is generated by `tools/update_imports.py`.

4. **`projector.py`**: Public API. `JvcProjector` connects, identifies the model and spec, and exposes `get()`, `set()`, `remote()`, `supports()`, `describe()`, and `capabilities()`.

5. **`cli.py`** / **`error.py`**: The `jvcprojector` command-line entry point, and the exception hierarchy rooted at `JvcProjectorError`.

Public exports from `jvcprojector/__init__.py`: `JvcProjector`, `Command`, and the `JvcProjector*Error` classes.

### Testing

Tests need no hardware. `conftest.py` provides `conn` (a mocked `Connection` used by `tests/test_device.py`) and `dev` (a mocked `Device` used by `tests/test_projector.py`); both accept indirect parametrization to change their behavior. pytest-timeout bounds each test at 10 seconds.

### Releasing

See `RELEASE.md`. Publishing a GitHub release tagged `vX.Y.Z` runs `.github/workflows/publish.yml`, which checks the tag against `__version__` in `jvcprojector/__init__.py` and uploads with PyPI trusted publishing.
